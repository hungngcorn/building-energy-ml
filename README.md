# Building Energy Load Prediction

A machine learning practice project using the UCI Energy Efficiency Dataset.

## Project Goal
Use building design features to predict Heating Load.

## Dataset
- 768 samples
- 8 input features
- Target: Heating Load

## Workflow
1. Data loading
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Correlation analysis
5. Train/Test split
6. Linear Regression
7. Model evaluation

## Current Results

| Model | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| Linear Regression | 2.18 | 3.03 | 0.912 |

## What I Learned
- Basic regression workflow
- Difference between training and testing data
- Correlation does not imply causation
- How to evaluate regression models using MAE, RMSE, and R²
